    Sign in hybrid modeYour wallet signs as it always has. Your ML-DSA-87 key signs the same intent next to it.
    
      
    
        
    Build a canonical intent for each transaction, sign it with the post-quantum key, and send both signatures. A verifier checks both, so a forged classical signature on its own gets nothing.
    
        
    
        
    intent.json holds the canonical intent, the exact bytes signed (signing_payload_hex) and the ML-DSA-87 signature. Anyone can check it with the CLI or the API:
    
        
    jq .signature intent.json > intent.sig.json
vantax verify -k treasury.pub.json -s intent.sig.json --hex "$(jq -r .signing_payload_hex intent.json)"

curl -s -X POST https://api.vantax-cybersecurity.com/api/v1/verify -H 'Content-Type: application/json' \
  -d '{"public_key":"<hex>","signature":"<hex>","message":"<signing_payload_hex>","encoding":"hex"}'
    
        
    Try signing in your browser
