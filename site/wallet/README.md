# Vantax Wallet (web build)

Non-custodial SOL / ETH / BTC browser wallet. Keys are generated and encrypted
in the browser and never leave the device. Unaudited beta, mainnet.

Live: https://wallet.vantax-cybersecurity.com/

This is the deployed static web build. Integrity of every file is pinned in
`manifest.sha256`; the page verifies itself against it at load.
